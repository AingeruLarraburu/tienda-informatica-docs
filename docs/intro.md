# Introducción

**TiendaTech** es una aplicación web para gestionar una tienda de informática: catálogo y stock, ventas (TPV y online), clientes, servicio técnico y compras a proveedores.

## Funcionalidades principales

| Módulo | Descripción |
|--------|-------------|
| [Inventario](modulos/inventario) | Catálogo, categorías, números de serie y control de stock |
| [Ventas y TPV](modulos/ventas-tpv) | Punto de venta, pedidos online, facturas y devoluciones |
| [Clientes](modulos/clientes) | Fichas, historial de compras y garantías |
| [Reparaciones](modulos/reparaciones) | Gestión de órdenes de servicio técnico |
| [Proveedores y compras](modulos/proveedores-compras) | Pedidos de compra y recepción de mercancía |
| [Informes](modulos/informes) | Métricas de ventas, stock y rentabilidad |

## Cómo usar esta documentación

1. Empieza por la [instalación](primeros-pasos/instalacion).
2. Configura los [roles y permisos](primeros-pasos/roles-y-permisos).
3. Consulta cada módulo según tu rol.
4. Si vas a integrar sistemas externos, revisa la [API](api/introduccion).

:::note
Esta es una documentación de ejemplo, pensada como plantilla para un proyecto real.
:::
