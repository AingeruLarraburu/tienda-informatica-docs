# Preguntas frecuentes

**¿Puedo gestionar varias tiendas?**
Sí, mediante almacenes y traspasos entre ellos.

**¿Cómo se gestionan los números de serie?**
Se registran en la recepción de compra y se asocian a la venta, lo que facilita la garantía.

**¿Se puede facturar con distintos tipos de IVA?**
Sí, el IVA se define por producto.

**¿Qué pasa si vendo sin stock?**
Por defecto se bloquea. Un administrador puede permitir ventas con stock negativo.
