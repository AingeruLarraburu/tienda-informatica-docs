# Informes

| Informe | Contenido |
|---------|-----------|
| Ventas | Por día, producto, categoría, vendedor y forma de pago |
| Stock | Valoración, rotación y productos bajo mínimo |
| Rentabilidad | Margen por producto y categoría |
| Reparaciones | Tiempos medios, tasa de aprobación de presupuestos |
| Compras | Gasto por proveedor y plazos de entrega |

Todos los informes se pueden filtrar por fechas y exportar a **CSV** o **PDF**.
