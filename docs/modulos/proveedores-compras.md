# Proveedores y compras

## Proveedores

Ficha con datos fiscales, condiciones de pago, plazos de entrega y catálogo de referencias.

## Pedidos de compra

1. Crea el pedido (manual o sugerido según stock mínimo).
2. Envíalo al proveedor.
3. Registra la **recepción** total o parcial.
4. Al recibir, el stock se actualiza y se registran los números de serie.
5. Concilia la factura del proveedor con el pedido.

## Estados

| Estado | Significado |
|--------|-------------|
| Borrador | En preparación |
| Enviado | Remitido al proveedor |
| Parcial | Recibido en parte |
| Recibido | Completado |
| Cancelado | Anulado |
