# Clientes

## Ficha de cliente

- Datos personales o fiscales (NIF/CIF).
- Dirección y contacto.
- Tipo: particular, autónomo o empresa.
- Consentimientos de comunicaciones (RGPD).

## Historial

Cada ficha muestra compras, facturas, equipos con garantía activa y reparaciones.

## Protección de datos

- Solo los roles autorizados ven datos fiscales.
- Los clientes pueden solicitar acceso, rectificación o supresión de sus datos.
- Los accesos a fichas quedan registrados en auditoría.
